# Brazilian E-Commerce Data Analysis (Olist Dataset)

##  Project Overview
As a Data Engineer, I developed this project to analyze 90k+ shopping orders. The goal was to build a robust data pipeline to merge multiple relational datasets and extract actionable business insights.

##  Tech Stack
* **Language:** Python
* **Data Manipulation:** Pandas, NumPy
* **Visualization:** Plotly, Seaborn, Matplotlib

##  Data Engineering Steps
1. **Data Integration:** Performed complex Merges and Joins across 5 different tables (Orders, Customers, Products, Items, and Translations).
2. **Data Cleaning:** Handled missing values and converted timestamps for time-series analysis.
3. **Aggregation:** Grouped data to find top-performing categories and cities.

##  Key Insights
* Identified the top 10 product categories by revenue.
* Analyzed sales trends over time to identify peak shopping months.
* Visualized geographical distribution of customers.
